# Conecta Bairro

O **Conecta Bairro** é um MVP acadêmico desenvolvido para apoiar pequenos comércios de bairro na organização de clientes, produtos e pedidos.

O projeto surgiu a partir da identificação de dificuldades no controle manual de pedidos, que pode causar dispersão de informações, atrasos, erros de registro e dificuldade no acompanhamento das solicitações.

## Objetivo

Desenvolver uma aplicação web simples e responsiva que permita centralizar as principais informações da operação de um pequeno comércio, facilitando o registro e o acompanhamento dos pedidos.

## Funcionalidades previstas

- Autenticação de usuários;
- Cadastro e consulta de clientes;
- Cadastro e consulta de produtos;
- Registro de pedidos;
- Inclusão de produtos e quantidades nos pedidos;
- Visualização dos pedidos em painel centralizado;
- Atualização do status do pedido;
- Consulta dos detalhes e valor total do pedido.

## Status dos pedidos

Os pedidos poderão assumir os seguintes estados:

- Recebido
- Em preparação
- Pronto
- Entregue

## Tecnologias

O MVP será desenvolvido utilizando:

- Python
- Flask
- SQLAlchemy
- SQLite
- HTML
- CSS
- Bootstrap

## Arquitetura

A aplicação seguirá uma estrutura em camadas, separando:

- Interface e apresentação;
- Regras de negócio;
- Persistência e acesso aos dados.

Essa separação busca facilitar a manutenção, os testes e a evolução do sistema.

## Público-alvo

O sistema é direcionado principalmente a proprietários, gestores e atendentes de pequenos comércios que necessitam organizar pedidos de maneira simples e centralizada.

## Desenvolvimento sustentável

O projeto está relacionado ao **ODS 8 – Trabalho Decente e Crescimento Econômico**, ao utilizar tecnologia para apoiar a produtividade e a organização de pequenos empreendimentos locais.

## Projeto acadêmico

Este repositório faz parte de uma experiência prática acadêmica de Análise e Desenvolvimento de Sistemas.
